# 갯벌 마을 회의 — 당진판

태블릿의 웹브라우저에서 사용하는 수업용 앱입니다. 앱은 index.html 한 파일로 실행되며 그림도 포함되어 있습니다.

## GitHub Pages에 게시하기

1. GitHub에 이 앱 전용 저장소를 만듭니다. 저장소 이름 예: tidal-village-dangjin.
2. 이 폴더의 index.html, .nojekyll, README.md만 올립니다. 학교 업무 폴더 전체를 올리지 않습니다.
3. 저장소 Settings → Pages에서 Source를 Deploy from a branch로 선택합니다.
4. Branch는 main, 폴더는 /(root)로 선택하고 저장합니다.
5. 게시가 끝나면 Pages에 표시되는 실제 주소를 태블릿에서 확인하고 학생들에게 공유합니다.

GitHub Free의 Pages는 공개 저장소에서 사용할 수 있습니다. 공개한 앱의 코드와 그림 파일도 다른 사람이 볼 수 있습니다.

## 학생 사용

선생님이 알려 준 주소나 QR코드를 열면 앱을 사용할 수 있습니다. 태블릿마다 HTML 파일을 내려받을 필요가 없습니다. 웹으로 처음 접속할 때는 인터넷이 필요합니다.

## 기록 저장 방식

진행 상황과 기록은 각 브라우저의 localStorage에 저장됩니다. 다른 기기나 교사의 기기로 자동 전송·공유되지 않습니다. 브라우저 데이터를 지우면 기록이 사라질 수 있습니다. 이전에 내려받은 HTML 파일에서의 기록은 웹주소의 기록으로 자동 이전되지 않습니다.

## 유지보수

수정된 앱을 index.html 이름으로 갱신하면 같은 주소로 새 버전을 공유할 수 있습니다. 수업 전에 태블릿에서 새로 고침하여 확인합니다.

## 준비 확인

2026. 10. 22. 원본을 변경하지 않고 게시용 index.html을 복사했습니다. 원본과 index.html의 SHA-256 해시가 같습니다. 외부 파일 참조나 네트워크 API 호출 없이 단일 파일로 구성되어 있습니다. 아직 GitHub 업로드나 공개 게시를 완료한 상태는 아닙니다.
